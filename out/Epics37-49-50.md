## R1 설계와 구현

1. Viewer 메뉴: 활성 link만 href를 가진 링크로 생성한다. disabled link는 메뉴 포커스·사유 설명은 유지하되 클릭 및 키보드로 URL 이동·download를 할 수 없는 비활성 메뉴 항목이다. 원본/생성 구분, Layer visibility, 편집/Undo·Redo, Tree/Canvas, JSON v2 파일·서버 저장 게이트는 기존 경로를 재사용한다.
2. 운영 로그 UI: LogRequestError가 response.status와 서버의 정제된 error.code를 구분한다. 타임라인 410 cursor expiry 및 확인된 503 LOG_STORE_UNAVAILABLE은 Timeline 목록·page만 지우고 별개로 인가된 메인 목록은 유지한다. 사용자는 같은 ID로 다시 조회할 수 있다. 401/403·G7_RUNTIME_UNAVAILABLE·알 수 없는 503·비정상 응답·network 오류는 기존 full clear를 유지한다.
3. 데이터/운영: G7/G4 인증·logs:read·Audit, 서버 JSONL rotation/DTO, CAD 원본·Version·Current·DB Schema, Migration, 운영 Volume은 수정하지 않는다. 프론트 UX는 서버 인가의 대체가 아니다.
