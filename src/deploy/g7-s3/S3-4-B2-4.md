## Three supplied stages and exact consistency contract

`inspectS34B24DisposableReplay(request)` accepts ONLY these exact keys:

- `scope="G7-S3-4B2-4-DISPOSABLE-REPLAY"`;
- `snapshotId: SNAP-*` and `sourceEpoch: E-*` opaque *claims*, not verified
  timestamp/actor or evidence IDs;
- `imagePair`: the existing B2-1 four-role local digest-pinned OCI
  App/Migrator and rollbackApp/rollbackMigrator manifest+config buffers;
- independent `source` (CAD baseline), `candidate` (7th Auth candidate),
  `rollback` (CAD baseline) stages. Each stage has exact `snapshotId`,
  `sourceEpoch`, its own `sqliteBytes`, `objects`, `markerBytes` and
  `markerVersionId`. Objects contain DB Version ID, `local` or `s3` kind,
  exact storage locator, supplied bytes and an opaque version ID for
  S3; Local objects carry no S3 version field. Values are private
  untrusted synthetic Buffers, with limits and safe reason codes.

The checker validates, **in this order**:

1. B2-1's `inspectS34B2OfflinePair` must return
   `LOCAL_DIGESTS_MATCH_NOT_REGISTRY_PROOF` with *four* distinct,
   locally coherent digest-pinned roles, source/version/schema/capability
   claims and CAD-baseline rollback label. It still sets
   `registryVerified=false`, `provenanceVerified=false`,
   `rollbackCompatible=false`: locally consistent labels/bytes are
   NOT authenticated publication, binary ABI compatibility, signed OCI
   provenance or proof the rollback executables are runnable.
2. All stages declare the **same** SNAP and source epoch. The S3 marker
   Buffer must decode to the expected synthetic scope/SNAP/Epoch, and
   the marker version claim and exact bytes must remain identical across
   all three stages. Identical untrusted claims **do not establish**
   genuine one-epoch source acquisition or versioned S3 origin.
3. Source/Candidate and Source/Rollback have exactly the same DB Version
   IDs, storage kinds, Local/S3 locators, S3 VersionId claims and
   **byte-for-byte equal Local CAD and S3 export contents**. No repeated
   source Version/locator, missing, extra, swapped, mutated or
   duplicate objects. At least one Local and one S3 sample.
4. The **Rollback** SQLite Buffer must be *byte-for-byte equal* to the
   Source baseline SQLite Buffer, not merely expose matching Version
   row counts or have the same SNAP claim. This is a supplied-buffer
   comparison, **not** proof that an independent rollback executed.
5. Reuse the B2-3 `assessS34B23DisposableMigration` validator on
   `source.sqliteBytes` / `candidate.sqliteBytes` and source object
   payloads. It checks SQLite `quick_check`, `foreign_key_check`,
   all seven CAD table rows including Current owner/Version/nextVersion,
   independent Local/S3 SHA/Size/locator contracts (S3 object UUID ≠
   DB Version UUID), all eight G7 Auth candidate tables and
   append-only Audit guards including rejection with **unchanged
   actual AuditEvent rows** after UPDATE/DELETE. Candidate cannot
   pass on truncated/incomplete/interrupted seventh Migration SQL.

If any check fails, return `BLOCKED` with a safe, non-data-bearing reason.
Successful **only synthetic** state is
`DISPOSABLE_REPLAY_MATCH_NOT_SITE_PROOF`. Even successful results
retain `registryVerified`, `provenanceVerified`, `rollbackCompatible`,
`writerQuiescenceVerified`, `sourceSnapshotVerified`,
`sameSnapshotRestored`, `restoreExecuted`, `rollbackExecuted`,
`operationalGo` and `runtimeActivated` ALL `false`. Only
`fourOciRolesLocallyConsistent` may be true for locally matched labels,
without implying authorization or successful App/Migrator execution.

## Fault-injection acceptance matrix

- Candidate SQLite Version SHA/Current/ownership/FK/8 Auth Schema/Audit
  changed or missing -> `CANDIDATE_INVARIANTS_BLOCKED`;
  candidate left at CAD baseline by interrupted 7th Migration -> BLOCKED.
- Rollback SQLite byte mutation or accidentally using the candidate
  Auth schema -> `ROLLBACK_SQLITE_BYTES_MISMATCH`.
- A missing, changed, swapped or repeated Local/S3 object/claimed version
  at any phase -> `CANDIDATE_OBJECT_MISMATCH` /
  `ROLLBACK_OBJECT_MISMATCH` / `SOURCE_OBJECT_DUPLICATED` or invalid
  packet; Local/S3 must be independently reconciled with CAD DB rows.
- Different SNAP/Epoch, corrupted marker Buffer, swapped marker
  version -> `SNAPSHOT_EPOCH_MISMATCH` or `S3_MARKER_MISMATCH`.
- Mutable OCI tag, mismatched registry reference, wrong image role or
  schema/rollback source/version labels -> `OFFLINE_OCI_PAIR_BLOCKED`.
- Unauthorized filesystem path or unknown input fields, malformed SQLite,
  out-of-bound Buffers -> `INVALID_DISPOSABLE_REPLAY_PACKET` /
  `CANDIDATE_INVARIANTS_BLOCKED`. Never echo source paths, credentials,
  bucket/object IDs, hashes, raw CAD bytes or private evidence in
  CI logs, GitHub Issues/PR comments or Chat.
