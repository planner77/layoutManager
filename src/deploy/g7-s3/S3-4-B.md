# #109 S3-4-B1 — disposable clone integrity rehearsal, no production access

S3-4-A is the read-only **attestation format** gate. B1 adds an offline
**byte-reading checker** for a *disposable, operator-owned /tmp clone*:
- Opens SQLite readonly and checks `quick_check`, `foreign_key_check`,
  Version/Current ownership and `next_version` monotonicity.
- Streams neither data nor secrets to stdout; checks local CAD and exported
  S3 object bytes against DB `file_size` and `sha256` using strict locator
  mapping, owner permissions and `O_NOFOLLOW` descriptor checks.
- Verifies expected CAD-only versus candidate G7 auth schema boundary.
  It **does not** apply Prisma SQL or run Docker/S3/network operations.
- Requires both a local CAD and an S3-export fixture to prevent treating a
  single-backend sample as proof of the dual-backend requirement.
- `snapshotId` is only an isolated clone label; identical labels do
  **NOT prove** source quiescence or actual same-snapshot capture. A true
  private B2 run must independently attest a writer freeze and a single
  DB/local CAD/S3 capture boundary before B1 output can be considered relevant.
- G7 Snapshot A/B CI exercises only synthetic data, not real operations.

### Isolated filesystem layout

The caller creates `/tmp/cad-g7-s3-b-<random>` owned by current UID and
mode 0700, all nested dirs 0700/files 0600. No symlinks. It contains:

```text
snapshot.json        # 0600: {"scope":"G7-S3-4B-DISPOSABLE-RESTORE","snapshotId":"SNAP-...","schema":"CAD_BASELINE" or "G7_CANDIDATE"}
snapshot.sqlite      # 0600 isolated restored SQLite backup
local/<location>/<version>/original.dxf
s3-export/<bucket>/cad/<object-uuid>/original.dxf
```

B1 invokes `inspectS34B1Clone(root,{snapshotId,schema})` on this
disposable root. `ISOLATED_INTEGRITY_ONLY` is a successful *clone
consistency* check, always with `operationalGo=false` and
`runtimeActivated=false`. Any mismatch returns `BLOCKED` with opaque
reason codes. No actual production DB/CAD/S3, Nginx, Compose, active
`src/prisma/migrations`, Auth/Write or GHCR changes.

### Remaining S3-4-B gates

- B2 **private actual** registry App/Migrator/rollback immutable OCI digest
  verification (source, version and trusted provenance, not just pattern).
- B2 owner-controlled writer quiescence/barrier and capture of *real* DB,
  local CAD, S3 versioned objects under one traceable private Snapshot ID.
- B2 genuine read/write isolated clone migration using the **quarantined**
  seven formal candidate Prisma migrations, failed migration injection,
  rollback app/migrator compatibility, actual restore and byte/FK/Audit checks.
- B3 trusted evidence binding after verified B2 (or S3-4-C); then S3-5
  explicit Owner release-specific GO/No-Go. CI synthetic checks never
  substitute for B2; without real private evidence report HOLD.
